# 강제력 종결어미

가이드라인에서 종결어미는 문체가 아니라 **규범의 세기**입니다. 독자는 어미로 "반드시 해야 하는지, 해도 되는지"를 판단합니다. 어미를 섞으면 문서의 강제력이 무너집니다.

측정값 (20종 1,450,128자 전체, `tools/analyze_corpus.py`):

| 등급 | 총계 | 표현별 |
|---|--:|---|
| **서술** | 3,073 | `~한다` 2,376 · `~된다/이다` 697 |
| **의무** | 1,332 | `~해야 한다` 865 · `~하여야 한다` 430 · `준수하여야 한다` 31 · `원칙으로 한다` 6 |
| **허용** | 789 | `~할 수 있다` 789 |
| **권고** | 104 | `권장한다` 45 · `권고한다` 36 · `바람직하다` 23 |
| **금지** | 53 | `금지한다` 25 · `하여서는 아니 된다` 21 · `하지 않도록 한다` 5 · `해서는 안 된다` 2 |
| 경어체 | 437 | `~습니다/입니다` 278 · `~하세요/하십시오` 159 |

## 다섯 등급

| 등급 | 어미 | 뜻 | 언제 |
|---|---|---|---|
| **의무** | `~해야 한다` / `~하여야 한다` | 이행하지 않으면 미준수 | 생략 시 시스템이 위험해지는 통제 |
| **금지** | `~을 금지한다` / `~하여서는 아니 된다` | 해서는 안 되는 행위 | 금지 자체가 통제인 경우 |
| **권고** | `~을 권고한다` / `~을 권장한다` / `~하는 것이 바람직하다` | 이행이 바람직하나 미이행이 미준수는 아님 | 환경에 따라 적용이 갈리는 통제 |
| **허용·선택** | `~할 수 있다` | 선택지 제시, 대안 허용 | 동등 수준의 대안이 있는 통제 |
| **서술** | `~한다` | 통제 요구사항의 기본형 | 통제항목 설명문, 사실 서술 |

## 가장 중요한 규칙 — 통제항목의 기본형은 `~한다`

서술 3,073 : 의무 1,332 로 **`~한다`가 `~해야 한다`의 2.3배**입니다. 보안통제 항목 해설서 단독으로는 `~한다` 883회 대 `~해야 한다` 25회입니다.

```
○  정보시스템 계정 식별자로 개인의 공개된 식별자 사용을 금지한다.
○  단말의 고유 식별자(MAC, TPM, 인증서 등)를 통해 단말을 식별하고,
   등록된 단말만 인증을 통해 시스템에 접근할 수 있도록 한다.
✕  단말의 고유 식별자를 통해 단말을 식별해야 한다.
```

**이 장르에서 `~한다`는 이미 요구사항입니다.** 통제항목 표에 올라간 문장은 그 자체로 "이렇게 하라"는 뜻이므로, `~해야 한다`를 덧붙이면 중복입니다. `~해야 한다`를 전부 쓰면 모든 항목이 같은 세기가 되어 등급 구분이 사라집니다.

`~해야 한다`는 **본문(장·절)에서 특정 통제를 강조할 때** 아껴 씁니다.

## 의무 표현의 두 변형 — 문서 안에서 하나만

| 표현 | 총계 | 쓰는 장르 |
|---|--:|---|
| `~하여야 한다` | 430 | **법령형 지침.** 국가 사이버보안 기본지침 단독 332회 |
| `~해야 한다` | 865 | **분야별 가이드라인.** 양자내성암호 133, 블록체인 84, 전력망 61 |

문서별 측정값이 이를 뒷받침합니다. 기본지침은 `하여야 한다` 332 : `해야 한다` 349 로 섞여 있지만(개정 누적의 흔적), 나머지 문서는 거의 한쪽에 몰립니다.

**가이드라인을 쓰면 `~해야 한다`로 통일하세요.** `~하여야 한다`는 법령 인용문 안에서만 그대로 둡니다.

## 금지 표현

```
가이드라인:  … 사용을 금지한다.            (25회)
법령형 지침:  … 하여서는 아니 된다.          (21회, 전부 기본지침)
```

`~해서는 안 된다`(2회)는 구어적이라 거의 쓰이지 않습니다. `~하지 않도록 한다`(5회)는 금지가 아니라 **서술 등급의 완곡 표현**이므로 금지 통제에 쓰면 세기가 약해집니다.

금지를 서술로 쓸 수 있으면 서술이 낫습니다 — `공개된 식별자 사용을 금지한다`는 `~한다`로 끝나지만 금지 통제입니다. **동사 자체가 금지(`금지한다`, `차단한다`, `제한한다`)면 어미는 `~한다`로 둡니다.** `제한한다` 81회, `차단한다` 578회, `제한` 673회가 모두 이 형태입니다.

## 권고 표현

전체 104회뿐입니다. **권고는 아껴 쓰는 등급입니다.**

```
… 가능하면 개인별 계정 사용을 권장한다.
… 분기별 1회 이상 점검하는 것이 바람직하다.
```

`권장한다`(45)와 `권고한다`(36)는 거의 같은 빈도로 쓰이며 의미 차이가 없습니다. 문서 안에서 하나로 고정하세요.

권고 등급의 쓸모는 **조건부 의무를 표현할 때**입니다. 조건을 명시할 수 있으면 권고보다 조건부 의무가 낫습니다.

```
△  정기적인 키 교체를 권고한다.
○  암호 키는 유효기간 만료 전에 교체해야 한다. 유효기간을 정하지 않은 경우
   연 1회 이상 교체하는 것이 바람직하다.
```

## 허용·선택 표현

`~할 수 있다` 789회. 두 가지로 쓰입니다.

1. **대안 허용** — `동등한 수준의 보증을 제공하는 외부 기관의 신원 검증 결과를 수용할 수 있다.` (의무 이행의 다른 경로를 열어 줌)
2. **능력 서술** — `… 조회 가능하도록 제한한다` 류의 사실 서술

1번으로 쓸 때는 **무엇의 대안인지가 문장 안에 있어야 합니다.** 대안 없이 `~할 수 있다`만 쓰면 독자는 해도 되고 안 해도 된다고 읽습니다.

전부 **실무 안내서·요약 리플릿**입니다. 본체 가이드라인 15종은 경어체가 0에 가깝습니다(AI보안 가이드북 31, 전체본 SW 공급망 20 — 머리말·발간사 부분).

규칙:

- **본체 가이드라인은 비경어체 평서형.** `~한다` / `~해야 한다`.
- **경어체는 짧은 실무 안내서·요약본·발간사에서만.** 그때는 문서 전체를 경어체로 통일하고 `~해야 합니다` / `~하세요`를 씁니다.
- 한 문서에서 섞지 마세요. 발간사·머리말만 경어체로 쓰고 본문은 비경어체로 돌아오는 것은 허용됩니다(코퍼스의 관행).

## 자체 점검 질문

1. 통제항목 설명문을 `~해야 한다`로 썼는가 → `~한다`로 내리세요.
2. `~하여야 한다`와 `~해야 한다`가 섞였는가 → 하나로 통일하세요.
3. 권고가 통제항목의 10%를 넘는가 → 조건부 의무로 바꿀 수 있는지 보세요.
4. `~할 수 있다`에 "무엇의 대안인지"가 쓰여 있는가.
5. 본문에 `~습니다`가 있는가 → 발간사 밖이면 고치세요.
